    내 관심 종목

    기업 분석

    회사 이름이나 티커를 넣으면 세 가지 분석을 보여줘요: 한 장 요약 · 지난 2~3년 스토리 · 지금 가격 판독
    보고서를 올려서 더 정확하게 분석하기 10-K · 10-Q · 사업보고서 · 분기보고서
    1. SEC EDGAR 열기 — 미국 증권거래위원회(SEC)의 전자공시시스템 SEC EDGAR를 새 창으로 열어요. 여기서 기업명을 치면 그 회사의 모든 공식 보고서를 찾을 수 있어요.
    2. 회사 검색 — Company name 칸에 회사 영어 이름(예: NVIDIA)을, 또는 Ticker 칸에 티커(예: NVDA)를 넣고 Search를 눌러요.
    3. 보고서 종류 거르기 — 회사 페이지의 Filing Type 칸에 10-K(1년 결산 보고서)를 넣고 Search. 분기 보고서가 필요하면 10-Q를 넣어요. 화면이 새 디자인이면 목록에서 Form이 10-K인 줄을 찾으면 돼요.
    4. 원하는 해 고르기 — 날짜(Filing Date)를 보고 최신 줄의 Documents 버튼을 눌러요. 스토리 분석까지 정확히 하려면 2~3년치를 받는 게 좋아요.
    5. 본문 파일 저장 — 표 맨 위에서 Type이 10-K인 줄의 …​.htm 파일 이름을 마우스 오른쪽 클릭 → ‘다른 이름으로 링크 저장’. 이 파일 하나면 충분해요. (폴더에 …-xbrl.zip이 보이면 그걸 통째로 받아 와도 돼요. 부록은 제가 빼요.)
    6. 여기에 올리기 — 위 ①에 회사 이름, ②에 받은 파일을 넣고 보고서와 함께 분석 요청을 누르면 끝이에요.
    1. DART 열기 — 금융감독원 전자공시시스템 DART를 새 창으로 열어요.
    2. 회사 검색 — 첫 화면 검색창에 회사 이름(예: 삼성전자)을 넣고 검색해요.
    3. 정기공시 고르기 — 공시 유형에서 정기공시를 고르면 사업보고서(1년)·반기보고서·분기보고서만 보여요.
    4. 보고서 열기 — 사업보고서 (2025.12)처럼 생긴 줄을 누르면 새 창이 열려요.
    5. 저장 — 새 창 위쪽의 다운로드 버튼으로 PDF나 첨부 파일을 받아요. 버튼이 안 보이면 브라우저의 인쇄 → PDF로 저장을 써도 돼요.
    6. 여기에 올리기 — 위 ①에 회사 이름, ②에 받은 파일을 넣고 요청하면 끝이에요.
