# 개미노트 · 매일 10분 주식 공부

어려운 주식 뉴스를 초등학생 말로 풀어 주는 무료 웹사이트예요. 로그인 없이 누구나 볼 수 있어요.

- 오늘의 시장 · 뉴스 따라가기 · 주요 일정(달력)
- 한국·미국 시가총액 상위 각 100개 종목, 일봉·주봉·월봉·연봉 차트(최대 5년)
- 하루 경제 상식 + 퀴즈, 용어 사전 199개

## 데이터가 바뀌는 방법
| 내용 | 누가 | 언제 |
|---|---|---|
| 종목 가격·차트 (`data/history`, `data/stocks/popular.json`) | GitHub Actions (`.github/workflows/prices.yml`) | 평일 한국·미국 장 마감 뒤 |
| 시장 설명·뉴스·일정·오늘의 상식 (`data/market`, `data/news`, `data/events`, `data/lesson`) | Claude 예약 작업 | 매시 40분 |

관심 종목, 퀴즈 기록, 10분 코스 체크는 방문자 각자의 브라우저에만 저장돼요.

투자 권유가 아니에요. 숫자는 표시된 출처와 기준 시각의 값이라 실제 시세와 다를 수 있어요.
